プライバシーポリシー（Ren Shorts Uploader）

Ren Shorts Uploader は、YouTube チャンネル「投資を見える化 レンの分析」の運営者が、自分のチャンネルに自分で作った動画を予約投稿するためだけに使う個人用ツールです。

  • 利用するのは運営者本人の Google アカウントだけで、第三者のデータは集めません。
  • YouTube API で扱うのは、動画のアップロードと予約設定、自分のチャンネルの情報の読み取りだけです。
  • ログインの許可情報は運営者のパソコンにだけ保存され、外部に送ったり共有したりしません。
  • 許可はいつでも Google アカウントの設定から取り消せます。

このツールは YouTube API サービスを利用しています（YouTube 利用規約、Google プライバシーポリシー）。
